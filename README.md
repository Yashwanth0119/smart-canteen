# 🍔 Smart Canteen Pre-Order System (Full-Stack MERN)

A modern full-stack web application for campus food pre-ordering with real-time order tracking, digital pickup tokens, and role-based access control.

## 🚀 Live Demo & Hosting
- **Frontend & Backend API:** Unified Node.js & Express server serving React SPA with Vite
- **Database:** MongoDB Atlas (Cloud NoSQL) with Mongoose ODM

## 🛠️ Technology Stack
- **Frontend:** React 18, Lucide Icons, Vanilla CSS Design System (Dark mode & glassmorphism)
- **Backend:** Node.js, Express.js (REST API)
- **Database:** MongoDB & Mongoose
- **Security:** JWT (HS256), bcrypt password hashing, HTTP-only session cookies, RBAC authorization, brute-force rate-limiting, NoSQL injection defenses

---

## 🏃 Local Setup & Running
```bash
# Install dependencies
npm install

# Run full-stack application (UI + API on port 5000)
npm start

# Run in frontend dev mode (Vite on port 3000)
npm run dev
```
